## 项目概述

### 1.1 项目简介

这是一个基于 **STM32F103** 微控制器的**智能防丢器系统**，结合了多种传感器和RFID技术，实现了：

- 🔔 **智能报警系统**：根据环境变化（光照、运动、距离）自动触发报警
- 🎫 **RFID授权管理**：通过刷卡切换系统工作模式
- 📺 **实时状态显示**：OLED屏幕显示传感器数据和系统状态
- 🔊 **声光报警**：蜂鸣器和LED灯双重报警提示

### 1.2 核心应用场景

**场景1：贵重物品防丢**
- 将系统放在背包/钱包里
- 刷卡进入警戒模式
- 检测到被移动或放入黑暗环境时自动报警

**场景2：环境监测**
- 实时监测光照强度
- 检测加速度变化（震动、移动）
- 超声波测距监测距离变化

**场景3：安全授权**
- 正常模式卡：解除所有报警，进入日常模式
- 警戒模式卡：启动防丢监测，异常时报警

### 2.2 系统工作模式

系统有两种工作模式，通过RFID刷卡切换：

#### 模式1：正常模式 (MODE_NORMAL)
- **触发方式**：刷"正常模式卡" (UID: 0xD4, 0xC8, 0xF5, 0x05)
- **工作状态**：
  - ✅ LED常亮（绿灯）
  - ✅ 显示传感器数据
  - ✅ 不触发任何报警
  - ✅ 蜂鸣器关闭
- **适用场景**：日常携带、在家使用

#### 模式2：警戒模式 (MODE_ALERT)
- **触发方式**：刷"警戒模式卡" (UID: 0x01, 0x2C, 0x99, 0x02)
- **工作状态**：
  - ✅ 实时监测所有传感器
  - ✅ 满足报警条件时触发报警
  - ✅ LED快速闪烁
  - ✅ 蜂鸣器响起
- **适用场景**：离开物品、防止被盗

### 3.1 OLED显示模块

#### 模块简介
- **型号**：SSD1306
- **尺寸**：0.96寸 128x64像素
- **接口**：I2C（软件模拟）
- **引脚**：PB6(SCL), PB7(SDA)

#### 功能实现

**显示内容（4行信息）：**

```
┌──────────────────────┐
│ Mode: NORMAL         │  ← 第1行：当前模式
│ Lux:   450 lx        │  ← 第2行：光照强度
│ Ax:   -234           │  ← 第3行：加速度X轴
│ Status: OK           │  ← 第4行：报警状态
└──────────────────────┘
```

**报警状态显示：**
- `Status: OK` - 正常
- `ALARM: Low Light` - 低光照报警（可能被放入包内）
- `ALARM: Fast Move` - 快速移动报警（可能被偷走）
- `ALARM: Outdoor` - 环境变化报警（距离突变）

#### 代码实现 (OLED.c/h)

```c
// 核心API
void OLED_Init(void);                    // 初始化OLED
void OLED_Clear(void);                   // 清屏
void OLED_ShowString(uint8_t Line, uint8_t Column, char *String);  // 显示字符串
void OLED_ShowChar(uint8_t Line, uint8_t Column, char Char);       // 显示单个字符
```

**实现原理：**
1. 软件模拟I2C协议（PB6/PB7）
2. 使用开漏输出模式
3. 发送命令和数据到SSD1306控制器
4. 使用内置字体库显示ASCII字符

### 3.2 RC522 RFID模块

#### 模块简介
- **频率**：13.56MHz
- **通信距离**：2-5cm
- **接口**：SPI
- **引脚**：PA5(SCK), PA6(MISO), PA7(MOSI), PA4(CS), PA3(RST)

#### 功能实现

**支持的RFID卡片：**

| 卡片类型 | UID | 功能 |
|---------|-----|------|
| 正常模式卡 | 0xD4, 0xC8, 0xF5, 0x05 | 切换到正常模式，解除报警 |
| 警戒模式卡 | 0x01, 0x2C, 0x99, 0x02 | 切换到警戒模式，启动监测 |

**读卡流程：**
```
1. 寻卡 (Request) → 检测卡片是否存在
2. 防冲突 (Anticoll) → 读取卡片UID
3. 比对UID → 判断是哪种卡片
4. 执行动作 → 切换模式并更新显示
```

#### 代码实现 (RC522.c/h)

```c
// 核心API
void RC522_Init(void);                              // 初始化RC522
uint8_t RC522_Request(uint8_t reqMode, uint8_t *TagType);  // 寻卡
uint8_t RC522_Anticoll(uint8_t *serNum);            // 读取UID
void RC522_Reset(void);                             // 复位模块
```

**工作原理：**
1. 使用STM32的SPI1硬件接口
2. 13.56MHz射频信号与卡片通信
3. 读取卡片的唯一识别码（UID，4字节）
4. 在主程序中比对UID切换模式

### 3.3 BH1750光照传感器模块

#### 模块简介
- **测量范围**：0-65535 lx
- **精度**：±20%
- **接口**：I2C（与OLED共用总线）
- **引脚**：PB6(SCL), PB7(SDA)
- **I2C地址**：0x23

#### 功能实现

**光照判断逻辑：**

| 光照值 (lx) | 环境判断 | 报警状态 |
|------------|---------|---------|
| > 500 | 室外/明亮 | 正常 |
| 50 - 500 | 室内 | 正常 |
| < 50 | 黑暗/包内 | **警戒模式下报警** |

**应用场景：**
- 物品被放入背包/口袋 → 光照从亮变暗 → 触发低光照报警
- 判断物品是否在室内/室外环境
- 节能：暗环境降低OLED亮度

#### 代码实现 (BH1750.c/h)

```c
// 核心API
void BH1750_Init(void);                    // 初始化BH1750
uint8_t BH1750_ReadLux(float *lux);        // 读取光照强度(lx)
```

**测量原理：**
1. 发送I2C命令启动连续测量模式
2. 读取16位光照数据
3. 转换为lux单位：`lux = (高字节 << 8 | 低字节) / 1.2`

### 3.4 MPU6050加速度传感器模块

#### 模块简介
- **类型**：6轴传感器（3轴加速度 + 3轴陀螺仪）
- **接口**：I2C（硬件I2C1）
- **引脚**：PB8(SCL), PB9(SDA)
- **I2C地址**：0x68

#### 功能实现

**加速度监测逻辑：**

```c
// 计算三轴加速度变化量
accelChange = |accel_x_new - accel_x_old| + 
              |accel_y_new - accel_y_old| + 
              |accel_z_new - accel_z_old|

// 判断是否快速移动
if (accelChange > 3000) {
    触发快速移动报警 (持续3秒)
}
```

**报警条件：**
- **静止状态下突然移动**：加速度突变 > 3000
- **持续报警机制**：检测到移动后持续报警15个检测周期（约3秒）
- **防止误报**：需要初始化后才开始检测

**应用场景：**
- 检测物品被拿起、移动
- 防盗：静止状态下被移动自动报警
- 跌落检测：加速度剧烈变化

#### 代码实现 (MPU6050.c/h)

```c
// 数据结构
typedef struct {
    int16_t accel_x, accel_y, accel_z;  // 加速度（三轴）
    int16_t gyro_x, gyro_y, gyro_z;     // 陀螺仪（三轴）
} MPU6050_Data;

// 核心API
void MPU6050_Init(void);                    // 初始化MPU6050
uint8_t MPU6050_Read(MPU6050_Data *data);   // 读取传感器数据
```

**测量范围：**
- 加速度：±2g / ±4g / ±8g / ±16g（可配置）
- 陀螺仪：±250°/s / ±500°/s / ±1000°/s / ±2000°/s

### 3.5 HC-SR04超声波测距模块

#### 模块简介
- **测距范围**：2cm - 400cm
- **精度**：±3mm
- **接口**：GPIO
- **引脚**：PB0(Trig), PB1(Echo)

#### 功能实现

**测距原理：**
```
1. Trig引脚发送10us高电平触发脉冲
2. 模块发出8个40kHz超声波脉冲
3. Echo引脚输出高电平，持续时间 = 往返时间
4. 计算距离：distance(cm) = pulse_width(us) * 0.017
```

**距离监测逻辑：**
```c
// 检测距离突变
if (|distance_new - distance_old| > 50cm) {
    环境变化报警（警戒模式）
}
```

**应用场景：**
- 检测物品周围环境变化
- 判断物品是否被移动到其他位置
- 可选功能：与蓝牙BLE结合实现近距离定位

#### 代码实现 (HCSR04.c/h)

```c
// 核心API
void HCSR04_Init(void);              // 初始化超声波模块
float HCSR04_GetDistance(void);      // 测距，返回距离(cm)
```

### 4.2 关键函数详解

#### 4.2.1 CheckRFID() - RFID检测与模式切换

```c
static void CheckRFID(void)
{
    uint8_t uid[5];
    uint8_t status;
    
    // 1. 寻卡
    status = RC522_Request(PICC_REQIDL, uid);
    if (status == MI_OK) {
        // 2. 读取UID
        status = RC522_Anticoll(uid);
        if (status == MI_OK) {
            // 3. 比对UID并切换模式
            if (CompareUID(uid, normalUID)) {
                // 正常模式卡
                currentMode = MODE_NORMAL;
                LED_On();           // LED常亮
                Buzzer_Off();       // 关闭蜂鸣器
                OLED_Clear();
            }
            else if (CompareUID(uid, alertUID)) {
                // 警戒模式卡
                currentMode = MODE_ALERT;
                OLED_Clear();
            }
            Delay_ms(500);  // 防抖
        }
    }
}
```

**要点：**
- 每次循环都检查是否有卡片靠近
- 识别到卡片后立即切换模式
- 500ms防抖避免重复触发

#### 4.2.2 UpdateSensors() - 传感器数据更新

```c
static void UpdateSensors(float *lux, int16_t *accel, float *distance)
{
    MPU6050_Data mpu_data;
    
    // 1. 读取光照强度
    if (BH1750_ReadLux(lux) != 0) {
        *lux = 0.0f;  // 读取失败，设为0
    }
    
    // 2. 读取加速度
    if (MPU6050_Read(&mpu_data)) {
        accel[0] = mpu_data.accel_x;
        accel[1] = mpu_data.accel_y;
        accel[2] = mpu_data.accel_z;
    }
    
    // 3. 读取距离
    *distance = HCSR04_GetDistance();
}
```

**执行频率：**
- 每4个主循环执行一次（4 × 50ms = 200ms）
- 即每秒更新5次传感器数据

#### 4.2.3 CheckAlarms() - 报警条件判断

```c
static void CheckAlarms(float lux, int16_t *accel, float distance)
{
    static float lastDistance = 0.0f;
    int32_t accelChange;
    
    // 报警条件1：低光照（< 50 lx）
    if (lux < LIGHT_THRESHOLD) {
        alarmState.lowLight = 1;
    } else {
        alarmState.lowLight = 0;
    }
    
    // 报警条件2：快速移动（加速度变化 > 3000）
    if (accelInitialized) {
        accelChange = abs(accel[0] - lastAccel[0]) + 
                      abs(accel[1] - lastAccel[1]) + 
                      abs(accel[2] - lastAccel[2]);
        
        if (accelChange > ACCEL_CHANGE_THRESHOLD) {
            alarmState.fastMove = 1;
            fastMoveAlarmCounter = 15;  // 持续3秒
        } else {
            if (fastMoveAlarmCounter > 0) {
                fastMoveAlarmCounter--;
                alarmState.fastMove = 1;
            } else {
                alarmState.fastMove = 0;
            }
        }
    }
    
    // 报警条件3：距离变化（> 50cm）
    if (lastDistance > 0) {
        float distChange = fabs(distance - lastDistance);
        if (distChange > DISTANCE_CHANGE_THRESHOLD) {
            alarmState.outdoor = 1;
        } else {
            alarmState.outdoor = 0;
        }
    }
    
    // 更新历史数据
    lastAccel[0] = accel[0];
    lastAccel[1] = accel[1];
    lastAccel[2] = accel[2];
    lastDistance = distance;
}
```

**报警策略：**
1. **低光照报警**：持续检测，光照恢复即解除
2. **快速移动报警**：检测到移动后持续报警3秒（防止瞬间误触）
3. **距离变化报警**：环境距离突变超过50cm

#### 4.2.4 UpdateDisplay() - OLED显示更新

```c
static void UpdateDisplay(float lux, int16_t *accel)
{
    char str[32];
    
    // 第1行：显示模式
    if (currentMode == MODE_NORMAL) {
        OLED_ShowString(1, 1, "Mode: NORMAL   ");
    } else {
        OLED_ShowString(1, 1, "Mode: ALERT    ");
    }
    
    // 第2行：光照强度
    sprintf(str, "Lux:%5.0f lx   ", lux);
    OLED_ShowString(2, 1, str);
    
    // 第3行：加速度X轴
    sprintf(str, "Ax:%6d      ", accel[0]);
    OLED_ShowString(3, 1, str);
    
    // 第4行：报警状态
    if (alarmState.lowLight) {
        OLED_ShowString(4, 1, "ALARM: Low Light");
    } else if (alarmState.fastMove) {
        OLED_ShowString(4, 1, "ALARM: Fast Move");
    } else if (alarmState.outdoor) {
        OLED_ShowString(4, 1, "ALARM: Outdoor  ");
    } else {
        OLED_ShowString(4, 1, "Status: OK      ");
    }
}
```

**显示优化：**
- 只在数据变化时更新，减少闪烁
- 使用固定格式字符串，保持显示稳定
- 报警优先级：低光照 > 快速移动 > 距离变化

#### 4.2.5 ControlAlarm() - 报警控制

```c
static void ControlAlarm(void)
{
    static uint8_t toggleCounter = 0;
    uint8_t alarmTriggered = 0;
    
    // 判断是否有报警触发
    if (currentMode == MODE_ALERT) {
        alarmTriggered = alarmState.lowLight || 
                        alarmState.fastMove || 
                        alarmState.outdoor;
    }
    
    if (alarmTriggered) {
        // LED闪烁（每150ms切换一次）
        toggleCounter++;
        if (toggleCounter >= 3) {  // 3 × 50ms = 150ms
            toggleCounter = 0;
            if (ledState) {
                LED_Off();
                ledState = 0;
            } else {
                LED_On();
                ledState = 1;
            }
        }
        
        // 蜂鸣器响
        Buzzer_On();
    } else {
        // 正常状态
        toggleCounter = 0;
        ledState = 0;
        if (currentMode == MODE_NORMAL) {
            LED_On();      // 正常模式LED常亮
        } else {
            LED_Off();     // 警戒模式无报警时LED熄灭
        }
        Buzzer_Off();
    }
}
```

**控制逻辑：**
- **报警时**：LED每150ms闪烁一次 + 蜂鸣器持续响
- **正常模式**：LED常亮，蜂鸣器关闭
- **警戒模式无报警**：LED熄灭，蜂鸣器关闭

### 7.4 常见问题

#### 问题1：OLED不显示
- 检查接线：PB6/PB7是否正确
- 检查I2C地址：默认0x78（8位）或0x3C（7位）
- 检查电源：必须是3.3V

#### 问题2：RFID读卡失败
- 检查SPI接线，特别是CS和RST
- 确认RC522供电为3.3V（不能是5V）
- 卡片距离天线2-3cm最佳

#### 问题3：加速度传感器数据异常
- 检查I2C1接线：PB8/PB9
- 确认MPU6050地址为0x68（AD0接GND）
- 检查上拉电阻（模块通常内置）

#### 问题4：报警误触发
- 调整阈值参数（见6.3节）
- 加速度阈值从3000调大到5000
- 光照阈值从50调小到20
