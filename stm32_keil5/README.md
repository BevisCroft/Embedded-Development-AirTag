# STM32 智能防丢器项目

## 🎯 项目简介

这是一个基于 **STM32F103** 的智能防丢器系统，集成了多种传感器和RFID技术，可以检测物品的环境变化并在异常时自动报警。

## ✨ 核心功能

- 🔔 **智能报警**：检测光照、运动、距离变化，异常时自动报警
- 🎫 **RFID授权**：刷卡切换正常/警戒模式
- 📺 **实时显示**：OLED屏幕显示传感器数据和系统状态
- 🔊 **声光提示**：LED灯闪烁 + 蜂鸣器响起

## 🛠️ 硬件模块

| 模块 | 型号 | 功能 |
|------|------|------|
| 主控 | STM32F103C8T6 | 核心控制器 |
| 显示屏 | OLED SSD1306 | 显示状态信息 |
| RFID读卡器 | RC522 | 刷卡切换模式 |
| 光照传感器 | BH1750 | 检测环境光照 |
| 加速度传感器 | MPU6050 | 检测运动和震动 |
| 超声波测距 | HC-SR04 | 测量距离变化 |
| 蜂鸣器 | 有源蜂鸣器 | 声音报警 |
| LED | 普通LED | 状态指示 |

## 📌 引脚连接速查

```
OLED/BH1750:  PB6(SCL), PB7(SDA)     - 软件I2C
MPU6050:      PB8(SCL), PB9(SDA)     - 硬件I2C1
RC522 RFID:   PA5/PA6/PA7(SPI1), PA4(CS), PA3(RST)
HC-SR04:      PB0(Trig), PB1(Echo)
蜂鸣器:        PA8
LED:          PA15
```

详细引脚定义请参考：[STM32引脚定义.md](./Docs/STM32引脚定义.md)

## 🚀 快速开始

### 1. 硬件连接
按照引脚定义连接所有模块，注意：
- ⚠️ RC522只能接3.3V（接5V会烧毁）
- ⚠️ 所有模块必须共地（GND相连）

### 2. 编译下载
1. 用Keil MDK打开 `airtag_stm32.uvprojx`
2. 编译工程（F7）
3. 连接ST-Link，下载程序（F8）

### 3. 使用说明

**准备RFID卡片：**
- 正常模式卡：UID = `0xD4, 0xC8, 0xF5, 0x05`
- 警戒模式卡：UID = `0x01, 0x2C, 0x99, 0x02`

**操作流程：**
1. 上电后系统进入正常模式，LED常亮
2. 刷"警戒模式卡"启动监测
3. 当检测到以下异常时自动报警：
   - 光照突然变暗（< 50 lx）→ 可能被放入包内
   - 快速移动（加速度变化 > 3000）→ 可能被拿走
   - 距离突变（> 50 cm）→ 环境变化
4. 报警时LED闪烁，蜂鸣器响起
5. 刷"正常模式卡"解除报警


## 🐛 常见问题

### Q1: OLED不显示
- 检查PB6/PB7接线
- 确认供电为3.3V
- 检查I2C地址（默认0x78）

### Q2: RFID读卡失败
- 确认RC522供电为3.3V（不能是5V）
- 检查SPI接线，特别是CS(PA4)和RST(PA3)
- 卡片距离天线2-3cm

### Q3: 加速度传感器无数据
- 检查PB8/PB9接线
- 确认MPU6050地址为0x68（AD0接GND）
- 检查I2C上拉电阻

### Q4: 报警误触发
- 调大阈值参数
- 加速度阈值：3000 → 5000
- 光照阈值：50 → 20

## 📊 系统工作流程

```
[上电初始化]
     ↓
[进入正常模式] → LED常亮
     ↓
[刷警戒模式卡]
     ↓
[启动监测]
     ├─ 读取光照
     ├─ 读取加速度
     └─ 读取距离
     ↓
[判断报警条件]
     ├─ 低光照? → 报警
     ├─ 快速移动? → 报警
     └─ 距离变化? → 报警
     ↓
[报警响应]
     ├─ LED闪烁
     ├─ 蜂鸣器响
     └─ OLED显示报警类型
     ↓
[刷正常模式卡] → 解除报警
```

## 💡 应用场景

### 场景1：贵重物品防丢
将系统放在钱包/背包里，启动警戒模式：
- 被移动 → 报警
- 被放入黑暗环境 → 报警

### 场景2：环境监测
实时监测：
- 光照强度
- 运动状态
- 距离变化

### 场景3：安全授权
- 借给朋友：给临时授权卡
- 找回物品：刷主卡确认
